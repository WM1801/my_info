== Проверка возможности создания Device Tree Overlay (DTO)

Оверлеи работают через файловую систему configfs. Выполните в SSH:

----
# 1. Проверяем, смонтирован ли configfs
ls -l /sys/kernel/config/

# 2. Если папка есть, проверяем директорию оверлеев
ls -l /sys/kernel/config/device-tree/overlays/
----

*Варианты развития событий:*

*Вариант А (Успех):* Директория overlays существует. Отлично, идем к Шагу 2.

*Вариант Б (Нужно смонтировать):* Директории нет, но configfs есть. Попробуйте смонтировать:

----
mount -t configfs configfs /sys/kernel/config
----

Если после этого overlays появилась — идем к пункту 2.

*Вариант В (Провал):* Ядро собрано без CONFIG_OF_OVERLAY. В этом случае DTO невозможен, и мы вернемся к варианту со скриптом в init.d (это тоже нормально для embedded).


== Пишем исходник оверлея (.dts)

Нам нужно создать текстовый файл, который переопределит пин PA19 с UART1_RTS на GPIO.

У нас SG2002, узел пинконтроллера в Device Tree обычно называется &pinctrl (или &sys_pinmux).

Создаем на своем ПК (или прямо на плате, если есть редактор vi/nano) файл pa19-gpio.dts со следующим содержимым:

---- 
/dts-v1/;
/plugin/;

/* Совместимость с нашим процессором */
/ {
    compatible = "sophgo,sg2002", "sophgo,cv1800b";
};

/* Обращаемся к узлу пинконтроллера */
&pinctrl {
    /* Создаем новое состояние для пина PA19 */
    pa19_as_gpio: pa19-gpio-pins {
        /* Указываем сам пин. В CV1800B пины часто называются просто "PA19" */
        pins = "PA19";
        /* Указываем функцию. Обычно это "gpio" или "gpio_in" / "gpio_out" */
        function = "gpio";
    };
};

/* Если UART1 жестко прописан в базовом дереве, его нужно отключить или изменить */
&uart1 {
    /* Принудительно убираем пин из UART1, если он там был */
    pinctrl-0 = <&pa19_as_gpio>; 
    /* Или, если UART1 вообще не нужен, можно раскомментировать строку ниже: */
    /* status = "disabled"; */
};
----


== Компиляция (.dts -> .dtbo)

Ядро не понимает текст, ему нужен бинарный файл .dtbo (Device Tree Blob Overlay).
Для этого нужен компилятор dtc (Device Tree Compiler).

*Если есть ПК с Ubuntu/Linux:*

----
sudo apt install device-tree-compiler
dtc -@ -I dts -O dtb -o pa19-gpio.dtbo pa19-gpio.dts
----

NOTE: Флаг -@ критически важен! Он добавляет таблицу символов, без которой оверлей не загрузится.

*Если компилируешь прямо на плате:*

Нужно установить dtc. В Buildroot/BusyBox его может не быть. 
Попробуй:
----
apt-get install device-tree-compiler  # Если есть apt
# или
opkg install dtc                      # Если есть opkg
----

NOTE: Если установить не получается, придется компилировать на ПК и перекидывать файл по SCP/SFTP.


== Загрузка оверлея на лету

Перекинь файл pa19-gpio.dtbo на плату (например, в /root/).
Теперь применяем его:

----
# 1. Создаем директорию для нашего оверлея (имя может быть любым)
mkdir /sys/kernel/config/device-tree/overlays/pa19-fix

# 2. Загружаем бинарник в эту директорию
cat /root/pa19-gpio.dtbo > /sys/kernel/config/device-tree/overlays/pa19-fix/dtbo
----


==  Проверка
Если команда cat прошла без ошибок, поздравляю! Ядро применило патч.
Теперь пин PA19 аппаратно переключен на GPIO.
Проверим это через sysfs (как раньше):
----
# Если пин уже экспортирован, сначала удалим его
echo 499 > /sys/class/gpio/unexport

# Экспортируем заново (теперь ядро должно создать его сразу как GPIO)
echo 499 > /sys/class/gpio/export

# Управляем
echo out > /sys/class/gpio/gpio499/direction
echo 0 > /sys/class/gpio/gpio499/value
----

Осциллограф должен показать 0В, и больше никаких конфликтов с UART не будет.


== Что делать, если при cat ... dtbo возникает ошибка?

Можно увидеть ошибку вроде Failed to apply overlay... или Invalid argument.
Это значит, что мы угадали не все названия в .dts файле.
Чтобы узнать точные названия пинов и функций, которые понимает драйвер SG2002, нужно "распечатать" базовое дерево устройств.
Выполни на плате:

----
# Дампим текущее дерево в текстовый вид
dtc -I fs -O dts /sys/firmware/devicetree/base > base.dts
----

Открой файл base.dts и найди там секцию pinctrl (или pinmux). Там ты увидишь, как именно называются пины (например, pins = "gpio_a_19"; вместо "PA19") и какие функции доступны.
