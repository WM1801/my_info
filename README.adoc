== Поиск

* В VS Code: Ctrl+Shift+F по тегу (например, `:keywords: gpio`)
* В браузере: открыть file:index.html[интерактивный каталог] — фильтрация по тегам и поиск

== Добавление новой статьи

. Создай `.adoc` файл в нужной папке, обязательно укажи `:keywords:` с тегами в заголовке
. (опционально) Сгенерируй PDF: Ctrl+Shift+B в VS Code (asciidoctor-pdf)
. Обнови каталог: `powershell -File scripts/generate-index.ps1` — автоматически обновятся README.adoc и index.html

=== kernel

* xref:kernel/Module_symvers.adoc[Module.symvers] — Module.symvers (Symbol Versions)* — это глобальный реестр (словарь) всех функций и переменных ядра, которые разрешено использовать внешним модулям.
  *Теги:* `driver, module, kernel_symvol, Module.symvers`

* xref:kernel/How_use_module_symvers.adoc[Как задействовать Module.symvers из ядра] — На сколько я понимаю, ядро мы дополняем модулями, в каждом модуле есть некие функции, некоторые из этих функций мы можем вызывать снаружи.
  *Теги:* `driver, module, kernel_symvol, Module.symvers`

* xref:kernel/read_documentation.adoc[Руководство по навигации и поиску в исходниках ядра Linux] — Разработка модулей ядра Linux требует умения эффективно работать с исходным кодом и документацией. Ядро содержит миллионы строк кода, тысячи функций и обширную документацию. Умение быстро находить нуж...
  *Теги:* `kernel, documentation, elixir, bootlin, ctags, cscope, navigation`

* xref:kernel/kernel_symvol.adoc[Символы ядра (Kernel Symbols)] — Когда разработчики Linux пишут код ядра, они пишут его на языке C. Там есть тысячи функций: sys_read, do_fork, tcp_sendmsg и переменные. Когда этот код компилируется, он превращается в машинные нули и...
  *Теги:* `kernel, symbols, kallsyms, module, cfi`
